Software de Análise de Extratos Bancários

Desenvolver um software que automatize o processamento do extrato bancário, para que seja capaz:


- Mostrar o total de créditos e débitos.
- Quantas transações bancárias existem em um mês específico.
- Quais são as 10 princiapis despesas
- Em qual categoria gasta mais dinheiro.

A aplicação vai ler um arquivo de texto que contém uma lista de transações bancárias, que será baixado do site do banco, esse texto é estruturado utilizando o formato CSV.
